# Пейзаж — звуковой холст

Основной интерфейс — музыкальный холст на весь экран по [композиции из Figma](https://www.figma.com/design/r9ZKy9SrKAYfBTndGQpbct/Леша?node-id=207-24). Сверху выбирается пейзаж, снизу находятся инструменты и таймлайн, справа — прокручиваемый инспектор. Версия на чистых HTML, CSS, JavaScript и Web Audio API.

Выбери предмет в палитре и нанеси на свободное место холста. Предпросмотр у курсора показывает будущий источник. X задаёт ноту, Y — громкость; перетаскивание редактирует оба параметра. С клавиатуры: Enter на холсте добавляет предмет, стрелки на источнике меняют его положение, Delete удаляет. Предметы звучат на отмеченных долях фразы и одновременно касаются нижней оси. Кольца заполняются по ходу фразы; пауза сохраняет их, «Сначала» очищает.

В инспекторе доступны два раздела:

- **Предмет:** высота, громкость, доли, уровень, панорама, октава, канал, расстройка, яркость, длительность и ADSR-огибающая. Есть прослушивание, приглушение, копирование и удаление. Для Тумана / Сияния можно отметить доли непрерывного звучания. Соседние отмеченные доли, в том числе последняя и первая, удерживают одну ноту без новой атаки; неотмеченные доли — паузы. По умолчанию отмечена вся фраза. Звук всегда проходит через Синт 2.
- **Звук и эффекты:** длина фразы 1–32 доли, тоника и лад, независимые волны / уровни / панорама / расстройка двух синтов, параметры барабанов, отдельные цепочки эффектов для синтов и барабанов, общий выход и схема маршрутизации. Тембр → насыщение → эхо → реверберация → общая компрессия. Все параметры подключены к звуковому движку.

«Ноты и волна» подсвечивает звучащие ноты, рисует спектр у нижней оси и реальную форму сигнала **внутри холста**. Полосы под осью нет; включение не меняет геометрию сцены или звук. Анализатор получает общий выход после эффектов и компрессии.

Расстановки, ритмы, настройки источников и каналов сохраняются в этом браузере отдельно для Осени и Космоса. Старые сохранения эскиза автоматически читаются. Темп и длина фразы общие.

[Подробная механика](./LANDSCAPE-MECHANICS.md). Основной интерфейс также доступен по `/sketches/landscape/`. Отдельный физический прототип **CONTACT** сохранён по `/sketches/contact/`.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173` и нажмите **Играть**. Звук начинается только после пользовательского жеста.

Для CONTACT откройте `http://localhost:4173/sketches/contact/` и нажмите **START**. Разрешите доступ к микрофону для ударов по корпусу. Если доступ запрещён, тачпад и скролл продолжают работать.

После разрешения сайт старается выбрать встроенный микрофон MacBook вместо подключённой гарнитуры. Удары анализируются в AudioWorklet; в браузере без AudioWorklet остаётся анализ через AnalyserNode. Чувствительность можно изменить константой `MIC_THRESHOLD` в начале `script.js`.

## Жесты CONTACT

| Жест | Звук и изображение |
| --- | --- |
| Удерживать клик тачпада или Space | Два синтезаторных голоса с плавной атакой и отпусканием; матрица рисует непрерывную линию звука. |
| Двигать указатель при удержании | Метка на изображённом тачпаде повторяет движение курсора. |
| Скроллить вверх/вниз | Непрерывно менять высоту тона; значение сохраняется. |
| Скроллить влево/вправо | Менять срез фильтра и долю второго голоса; значение сохраняется. |
| Стукнуть возле микрофона | Короткий металлический удар и световые волны от обоих краёв матрицы к центру. |
| Нажать боковую зону колонки на экране | Тот же удар и волна от выбранной стороны. |
| Нажать 1 или 2 | Переключить форму волны соответствующего синтезаторного голоса. |

У браузера нет надёжной информации о том, с какой стороны корпуса пришёл звук одного микрофона. Поэтому физический удар запускает симметричные волны, а удар по экранной боковой зоне — волну от выбранной стороны. Положение пальцев на физическом тачпаде также не раскрывается браузеру: метка показывает положение курсора и направление wheel-жеста.

Shortap читает датчик движения MacBook через нативное приложение. Для такого же распознавания ударов по корпусу здесь понадобится отдельный macOS-мост; микрофонный режим остаётся акустическим приближением.

## Звуковой тракт CONTACT

```text
Synth 1 oscillator → channel gain → low-pass filter → ADSR gate ┐
                                                             ├→ synth bus → soft drive ┐
Synth 2 oscillator → channel gain → low-pass filter → ADSR gate ┘                          │
                                                                                        ├→ master gain → compressor → speakers
Mic → high-pass → analyser → transient detector → percussion trigger                    │
Percussion tone + filtered noise → drum bus ─────────────────────────────────────────────┤
                                   └→ short feedback delay → quiet wet return ────────────┘
```

Синтезаторные каналы независимы; формы волн выбираются клавишами 1 и 2. Четыре этапа обработки: фильтрация, мягкое насыщение, короткая задержка и компрессор. Микрофон подключён только к анализатору и никогда не выводится в динамики. Все звуки проходят через один AudioContext и общий ограниченный master gain.
