# Пейзаж — звуковой холст

**Открыть инструмент:** [pentaoo.github.io/synth_zahar](https://pentaoo.github.io/synth_zahar/).

Основной интерфейс — музыкальный холст на весь экран по [композиции из Figma](https://www.figma.com/design/r9ZKy9SrKAYfBTndGQpbct/Леша?node-id=207-24). Сверху переключаются виды «Фраза» и «Композиция», снизу — предметы, таймлайн и транспорт, справа — настройки. Используется одна зелёная тема. Версия на чистых HTML, CSS, JavaScript и Web Audio API.

При первом запуске уже есть **четыре разные фразы**: у них отличаются ноты, ритмы и тембры. В виде «Композиция» нажми «Играть», чтобы послушать все партии вместе; в виде «Фраза» играет только выбранная фраза. Ранее отредактированные композиции остаются на месте.

В виде **«Композиция»** партии стоят вложенными кольцами. Можно добавить бас, мелодию или барабаны, до четырёх слоёв. У каждого свои фразы, громкость и приглушение. Расстояние между сегментами одинаково по всей толщине кольца. Двойной клик открывает выбранную фразу для редактирования и ставит композицию на паузу. Один клик выбирает фразу; во время игры она назначается следующей на границе сегмента только в своём кольце. Перетаскивание перестраивает порядок: соседние фразы уступают место, а порядок исполнения меняется после отпускания. Звучащий луп продолжается. Escape отменяет перетаскивание.

**«+» в центре** добавляет слой с выбором партии. **«+» сверху между фразами каждого кольца** добавляет фразу с исходным музыкальным рисунком. Снаружи выбранной фразы находятся **← →**, **↻** (число повторов 1–32), **×** (удаление), **↗** (редактирование) и **⧉** (копирование). Фразу можно удалить клавишей Delete / Backspace, переместить Alt+← / Alt+→. Копия независима от оригинала. Доступно до восьми фраз в каждом кольце. Удаление последней фразы удаляет её кольцо; кнопка × в настройках слоя удаляет кольцо целиком.

Все кольца проходят оборот за одинаковое время. **BPM справа внизу общий для всех**, а «Круг» задаёт длину оборота в долях. Например, при 32 долях четыре внешних сегмента занимают по 8 долей, три внутренних — по 10⅔. Повторы ↻ укладываются внутри времени сегмента.

Переключатель **«По кругу»** включает автоматическую последовательность: после заданных повторов звучит следующая фраза, после последней — первая. Ручной выбор имеет приоритет; повторное нажатие снимает его. Пауза сохраняет позицию и очередь, «Сначала» начинает все кольца одновременно. Переключение в «Фразу» ставит композицию на паузу; «Играть» зацикливает только выбранную фразу с общим BPM.

В виде **«Фраза»** выбери предмет в палитре и нанеси на холст. X задаёт ноту, Y — громкость; перетаскивание редактирует оба параметра. Enter на холсте добавляет предмет, стрелки на источнике меняют его положение, Delete удаляет. Предметы звучат на отмеченных долях и одновременно касаются нижней оси. Кольца заполняются по ходу лупа; пауза сохраняет их, «Сначала» очищает.

Внизу есть наборы **«Барабаны»**, **«Бас»**, **«Мелодия»** и прежние предметы **«Пейзаж»**. Библиотека содержит 34 тембра: 16 ударных (три бочки, три снейра, три хэта, хлопок, римшот, два тома, шейкер, райд, металл), 8 басов и 10 мелодических инструментов. Выбери карточку, прослушай её кнопкой ▷ и нанеси на холст; остальные карточки доступны горизонтальным скроллом. При выборе слоя открывается соответствующий набор. Новые барабанные фразы начинают с бочки, снейра и хэта.

В инспекторе **«Инструмент»** меняет тембр выбранного предмета, сохраняя позицию и рисунок долей. У синтезаторных предметов можно выбрать свою волну или **«По каналу»**, чтобы использовать общую волну Синт 1 / Синт 2. Бас проходит через Синт 1, мелодия — через Синт 2, ударные — через канал барабанов и их эффекты. Тембры синтезируются локально в Web Audio; инструмент, волна и все правки сохраняются в раскладках.

Справа доступны три раздела:

- **Предмет:** высота, громкость, доли, канал, панорама, октава, тембр и ADSR. «Туман» держит ноту на соседних отмеченных долях, включая границу лупа; паузы прерывают удержание. Звук проходит через Синт 2.
- **Звук и эффекты:** длина фразы 1–32 доли, тоника и лад, независимые волны двух синтов, барабаны, отдельные цепочки эффектов, общий выход и схема маршрутизации. Тембр → насыщение → эхо → реверберация → общая компрессия.
- **Раскладки:** сохранение всей композиции в `.landscape.json` и импорт. Сохраняются все слои, их громкость и приглушение, общий темп, длина оборота, порядок, повторы, позиции, доли и настройки всех фраз. Некорректный файл не меняет композицию; успешный импорт можно отменить кнопкой ↶. Старые раскладки читаются; прежние космические источники переходят к предметам единой темы с сохранением звука.

«Ноты и волна» показывает звучащие ноты, спектр и реальную форму общего сигнала после эффектов. Настройки и фразы автоматически сохраняются в этом браузере; отдельные файлы позволяют переносить композиции. BPM общий для всей композиции; длина и рисунок фразы редактируются отдельно.

[Подробная механика](./LANDSCAPE-MECHANICS.md). Основной интерфейс также доступен по `/sketches/landscape/`. Отдельный физический прототип **CONTACT** сохранён по `/sketches/contact/`.

## Публикация

GitHub Pages публикует сайт из ветки `main`, папки `/ (root)`. После отправки изменений в `main` сайт обновляется автоматически. `.nojekyll` сохраняет обычную статическую структуру проекта без обработки Jekyll.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173` и нажмите **Играть**. Звук начинается только после пользовательского жеста.

Для CONTACT откройте `http://localhost:4173/sketches/contact/` и нажмите **START**. Разрешите доступ к микрофону для ударов по корпусу. Если доступ запрещён, тачпад и скролл продолжают работать.

После разрешения сайт старается выбрать встроенный микрофон MacBook вместо подключённой гарнитуры. Удары анализируются в AudioWorklet; в браузере без AudioWorklet остаётся анализ через AnalyserNode. Чувствительность можно изменить константой `MIC_THRESHOLD` в начале `script.js`.

## Выделение и общие настройки

Протяни мышь по пустому месту: рамка выбирает несколько предметов в «Фразе» или несколько фраз из разных колец в «Композиции». Shift добавляет к выделению; Shift-клик включает или исключает отдельный объект. ⌘A / Ctrl+A выбирает все объекты на активном холсте. Перетаскивание выделенного предмета перемещает всю группу.

Справа редактируются общие параметры выделения. «Разные» и полосатые доли обозначают несовпадающие значения. Нажатие на смешанную долю включает её у всех выбранных предметов; повторное выключает. Остальные доли и параметры сохраняются. В композиции выпадающий список позволяет применить изменение ко всем предметам выбранных фраз или к одному типу инструмента. Выделение рамкой не назначает фразы на проигрывание.

Delete / Backspace или кнопка удаления убирают всё выделение. Одно «Отменить» или ⌘Z / Ctrl+Z восстанавливает группу целиком. Если удалить все фразы кольца, удалится и слой. Можно удалить все кольца: пустая композиция сохраняется после перезагрузки, останавливает звук и позволяет добавить новый слой через «+». Escape во время протягивания отменяет рамку.

## Жесты CONTACT

| Жест | Звук и изображение |
| --- | --- |
| Удерживать клик тачпада или Space | Два синтезаторных голоса с плавной атакой и отпусканием; матрица рисует непрерывную линию звука. |
| Двигать указатель при удержании | Метка на изображённом тачпаде повторяет движение курсора. |
| Скроллить вверх/вниз | Непрерывно менять высоту тона; значение сохраняется. |
| Скроллить влево/вправо | Менять срез фильтра и долю второго голоса; значение сохраняется. |
| Стукнуть возле микрофона | Короткий металлический удар и световые волны от обоих краёв матрицы к центру. |
| Нажать боковую зону колонки на экране | Тот же удар и волна от выбранной стороны. |
| Нажать 1 или 2 | Переключить форму волны соответствующего синтезаторного голоса. |

У браузера нет надёжной информации о том, с какой стороны корпуса пришёл звук одного микрофона. Поэтому физический удар запускает симметричные волны, а удар по экранной боковой зоне — волну от выбранной стороны. Положение пальцев на физическом тачпаде также не раскрывается браузеру: метка показывает положение курсора и направление wheel-жеста.

Shortap читает датчик движения MacBook через нативное приложение. Для такого же распознавания ударов по корпусу здесь понадобится отдельный macOS-мост; микрофонный режим остаётся акустическим приближением.

## Звуковой тракт CONTACT

```text
Synth 1 oscillator → channel gain → low-pass filter → ADSR gate ┐
                                                             ├→ synth bus → soft drive ┐
Synth 2 oscillator → channel gain → low-pass filter → ADSR gate ┘                          │
                                                                                        ├→ master gain → compressor → speakers
Mic → high-pass → analyser → transient detector → percussion trigger                    │
Percussion tone + filtered noise → drum bus ─────────────────────────────────────────────┤
                                   └→ short feedback delay → quiet wet return ────────────┘
```

Синтезаторные каналы независимы; формы волн выбираются клавишами 1 и 2. Четыре этапа обработки: фильтрация, мягкое насыщение, короткая задержка и компрессор. Микрофон подключён только к анализатору и никогда не выводится в динамики. Все звуки проходят через один AudioContext и общий ограниченный master gain.
