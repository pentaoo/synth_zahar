# Уроборос: первая итерация и её проверка · 30 октября 2026

Исторический отчёт. После этого прохода автор выявил дефекты стыка головы, заглатывания и перехода; прежние тесты не доказывают их визуальную корректность. Актуальная доработка и проверка: [results-revision/QA.md](../results-revision/QA.md).

Рабочая версия: [localhost / Уроборос](http://127.0.0.1:4173/sketches/ouroboros/). Из корня репозитория: `python3 -m http.server 4173 --bind 127.0.0.1`. Нужен браузер с WebGL 2, AudioWorklet и Web Audio; звук запускается нажатием «Играть».

## Результат

Три вложенных тела соответствуют басу, пианино и барабанам. Оригинальная партитура, общий виниловый транспорт, шум скретча, короткий докрут и старый Slip сохранены. Клик открывает крупный вид с четырьмя работающими группами канальных параметров. Drag отменяет выбор и сохраняет захват над интерфейсом. Материальные координаты кожи и её толщина не сжимаются при pinch; сокращается видимая длина тела. Дальнейшее сжатие у предела запускает последний завиток и коллапс в точку. Источники и хвосты эффектов плавно гаснут. Новый круг запускается явно и сохраняет канальные настройки.

Чернила используют реальный анализ общего выхода после эффектов и канальные анализаторы. Вязкая масса расширяется / вытягивается, упирается в внутреннее тело и возвращает капли. Живой голос и макрообработка сохраняются. Общий вид и миниатюра получают одно состояние.

Собственные растровые ассеты и фактические промпты: [GENERATION.md](../../../sketches/ouroboros/assets/GENERATION.md). Референсы задания не вырезались в итоговые ассеты. Детальная кожа 2172 × 724 и прозрачная голова 1536 × 1024 сохранены без апскейла.

## Живая проверка

Проверено во встроенном Chromium с реальными WebGL 2 и AudioWorklet, основной размер 1366 × 768 (16:9), дополнительно 1280 × 800.

| Действие | Наблюдение |
| --- | --- |
| Запуск исходной музыки | Все три канальных анализатора получили ненулевой сигнал; пример RMS: 0,161 / 0,234 / 0,059 |
| Клик по телу на паузе | Открылась партия; музыка осталась на паузе, позиция 0 |
| Переход к пианино во время игры и возврат миниатюрой | Позиция продолжила идти; скорость 1×; остальные каналы продолжили звучать |
| Громкость пианино в 0 | Его RMS после затухания около 0,00023; RMS баса и барабанов остался ненулевым; их параметры не изменились |
| Волна, панорама, насыщение, эхо выбранного канала | Значения изменились только в выбранном канале, фраза не перезапустилась |
| Плотность удара барабанов в 100% | Изменилось только значение барабанов; вместо выбора волны показана «Плотность удара» |
| Drag крупного тела через область настроек | Получен реверс до −4,279×; захват сохранился, настройки не изменились, переход не открылся |
| Отпускание drag | Позиция отпускания 0,940223, далее 0,959646 при базовой скорости 1×; возврата к скрытому времени нет |
| Контакт с чернилами | Зарегистрирован жест непрерывного голоса; обработка и визуальная масса отвечают контакту |
| Сжатие клавишей минус | Три радиуса уменьшились с одним коэффициентом; ширины 36,96 / 23,65 / 13,01 px оставались постоянными до финального завитка; скорость дошла до 2,8571× |
| Два дополнительных сжатия у минимума | Коллапс завершился; все радиусы, ширины и видимые длины стали 0, пик транспорта 0, RMS общего выхода после master 0,00000 |
| «Новый круг» | Вернулись масштаб 1, скорость 1× и исходная партитура; параметры каналов сохранились |
| Старый `?transport=slip` | Загрузились три канала; wheel дал реверс до −9,906×, после возврата `phase` совпала с `backgroundPhase`, `slipMix=0` |
| Диагностика браузера | В основной версии и Slip не найдено ошибок / предупреждений JavaScript и WebGL |

Клавиатурой проверены выбор партии, диапазоны Home / End, минус, новый круг. Reduced motion, потеря фокуса в том числе при незавершённой инициализации, системный momentum и Safari GestureEvent покрыты логическими тестами; это не заменяет проверку физических жестов на MacBook.

## Конкретные ограничения

- Физический pinch и ощущение коротких скретчей на реальном тачпаде MacBook, Safari, сквозная задержка и частота кадров на устройстве отдельно не измерялись. В этой сессии сжатие в браузере проверялось клавиатурным эквивалентом, пути ctrl+wheel / GestureEvent — тестами.
- Вывод сигнала и работа канальных параметров проверены анализаторами и тестами; художественный баланс, узнаваемость пианино и комфортная громкость требуют авторского прослушивания.
- У браузерного управления нет доступной записи экрана со звуком. Приложен GIF реального интерфейса без аудио; он не заменяет финальный скринкаст музыкального исполнения для сдачи.
- Рендерер требует WebGL 2. Макромасштаб рассчитан под оригиналы при DPR 2; отдельная проверка иных GPU и DPR выше 2 не выполнялась.
