# Изображения для предпросмотра

Подборка подготовлена 13 октября 2026 года. Для загрузки и переноса на другой компьютер все изображения и этот список собраны в `../preview-screenshots.zip`.

## Текущий дизайн — 1920 × 1080

Четыре PNG сняты из работающей локальной версии инструмента в браузере Chrome. Размер окна содержимого — 1920 × 1080, масштаб пикселей — 1. Изображения не увеличивались и не обрезались. В кадрах запущено воспроизведение; волна и спектр показывают сигнал инструмента.

| Файл | Подпись для предпросмотра |
| --- | --- |
| [01-composition.png](./current/01-composition.png) | Композиция: восемь фраз в круговом секвенсере, два синтезаторных голоса и ручки общего звучания. |
| [02-phrase.png](./current/02-phrase.png) | Фраза: положение источников задаёт высоту и громкость; на поле видны звучащие ноты, спектр и реальная звуковая волна. |
| [03-live-editor.png](./current/03-live-editor.png) | Исполнение и редактирование: открытая фраза под круговым секвенсером, её источники и доли вступления. |
| [04-layered-composition.png](./current/04-layered-composition.png) | «Тихий круг»: четыре одновременные партии — гармония, бас, мелодия и барабаны. |

Для основных изображений раздела «Интерфейс» подойдут **02** и **04**; для демонстрации редактирования во время исполнения — **03**. Изображение **01** показывает текущую стартовую композицию из восьми фраз. Для **04** в отдельной временной сессии браузера импортирован уже существовавший локальный музыкальный эскиз. Сам JSON в подборку не включён.
